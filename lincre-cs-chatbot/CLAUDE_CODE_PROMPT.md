# Claude Code에 붙여 넣을 구현 프롬프트

아래 내용을 Claude Code에 그대로 붙여 넣고 시작하세요.

```text
너는 초보자에게 설명을 잘하는 시니어 프론트엔드 개발자야.

현재 폴더에 LINCRE 코스메틱·패션 쇼핑 CS 챗봇을 만들어줘.
구매자가 주문용 URL 하나를 클릭하면 한 화면에서 아래 흐름을 끝낼 수 있어야 해.

1. 자연스러운 한국어 채팅으로 배송, 환불, 취소, 반품, 교환, 주문 조회, 상품 추천 문의에 답하기
2. 주문 리스트와 주문 상태 보여주기
3. 상품을 장바구니에 담고 수량 변경하기
4. 총액을 계산하고 주문 정보를 입력하기
5. 결제 준비 화면을 보여주고 실제 PG사 결제창을 연결할 수 있는 함수 위치 남기기

브랜드/디자인 조건:
- 전체 컬러는 코발트 블루, 스카이 블루, 파우더 블루, 흰색 중심
- 첨부 로고는 public/assets/lincre-logo.png로 사용
- public/assets/lincre-mascot.png는 양모 펠트 스타일 3D 수달 상담 캐릭터로 사용
- 두 번째 참고 이미지처럼 별빛, 밝은 그라데이션, 둥근 말풍선, 부드러운 카드 UI를 사용
- 모바일에서도 채팅과 주문/장바구니 흐름이 깨지지 않게 반응형으로 구현

대화 규칙:
- AI처럼 딱딱한 표현 대신 사람이 직접 답하는 듯한 짧고 따뜻한 한국어를 사용
- 답변에는 상황에 맞는 이모티콘을 1~2개만 사용
- 배송/환불/취소/반품/교환 문의는 임의로 확정하지 말고 “담당자에게 연결해 확인해드린다”는 흐름으로 답변
- 답변 아래에 담당자 연결 요청 버튼을 제공
- 배송/택배/운송장/도착, 환불/환급/돈 돌려, 취소/주문 취소, 반품/돌려보내기, 교환/사이즈 교환 등의 동의어를 인식
- `배숭`, `베송`, `환블`, `환뷸`, `결재`, `주뮨`, `반퓸` 같은 오타도 인식
- 의도가 애매하면 다시 물어보는 자연스러운 fallback 답변을 제공
- 사용자 입력은 HTML escape 후 화면에 출력

초보자용 구현 순서:
1. index.html, styles.css, app.js 구조를 먼저 설명
2. 화면 골격과 샘플 주문/상품 데이터를 구현
3. 키워드 인식과 오타 보정 구현
4. 장바구니와 localStorage 구현
5. 데모 결제 준비 흐름 구현
6. node --check app.js와 화면 수동 테스트 방법을 안내

보안 규칙:
- 카드번호, 비밀번호, PG secret key를 브라우저 코드나 채팅 로그에 저장하지 않기
- 실제 결제는 startRealPayment()에서 서버의 /api/payment/prepare를 호출하도록 분리
- 실제 운영 전에는 상품/주문 API, 배송 조회 API, CRM/상담원 연결 API를 연결

작업이 끝나면 변경한 파일, 테스트한 키워드, 실제 운영 전에 해야 할 일을 한국어로 요약해줘.
```
