# LINCRE Concierge - Claude Code 작업 지침

## 프로젝트 목표

코스메틱·패션 구매자가 주문 URL 하나만 클릭하면 같은 화면에서 CS 문의, 주문 조회, 상품 선택, 장바구니, 결제 준비까지 할 수 있는 웹앱을 유지·확장한다.

## 반드시 유지할 사용자 경험

1. 첫 화면에서 채팅창과 주문 리스트가 동시에 보인다.
2. 블루톤, 별빛, 말풍선 중심의 밝은 테마를 유지한다.
3. `public/assets/lincre-logo.png` 로고와 `public/assets/lincre-mascot.png` 캐릭터를 계속 사용한다.
4. 답변은 딱딱한 봇 말투보다 짧고 자연스러운 한국어를 사용하고, 상황에 맞는 이모티콘을 1~2개 넣는다.
5. 배송, 환불, 취소, 반품, 교환은 임의로 확정하지 않고 담당자 확인으로 연결한다.
6. 오타가 있어도 의도를 추정한다. 예: `배숭`, `베송`, `환블`, `결재`, `주뮨`.
7. 카드번호·비밀번호·PG secret key는 채팅창이나 브라우저에 저장하지 않는다.

## 현재 파일 구조

- `index.html`: 화면 골격과 접근성 라벨
- `styles.css`: 블루톤·반응형 UI·말풍선·카드 스타일
- `app.js`: 상품, 장바구니, 메시지, 키워드 인식, 데모 결제 흐름
- `public/assets/lincre-logo.png`: 사용자가 제공한 로고
- `public/assets/lincre-mascot.png`: 양모 펠트 스타일 상담 캐릭터
- `docs/style-reference.png`: 참고 스타일 이미지

## 키워드 인식 규칙

`app.js`의 `intentAliases`, `typoReplacements`, `detectIntent()`를 함께 수정한다.

- 배송 계열: 배송, 택배, 운송장, 출고, 도착
- 환불 계열: 환불, 환급, 돈 돌려
- 취소 계열: 취소, 주문 취소
- 반품 계열: 반품, 돌려보내기
- 교환 계열: 교환, 사이즈 교환, 색상 교환
- 주문 계열: 주문, 내 주문, 주문 조회, 주문번호
- 상품 계열: 추천, 피부, 사이즈, 코디, 화장품, 패션
- 결제 계열: 결제, 카드, 페이, 구매

오타 보정은 사용자의 문장을 과하게 바꾸지 말고, 의도 분류 직전에만 적용한다. 모호하면 `fallback` 답변을 사용한다.

## 수정 작업 순서

1. 먼저 어떤 사용 흐름이 바뀌는지 한 문장으로 설명한다.
2. 관련 파일만 최소 범위로 수정한다.
3. `python -m http.server 4173`로 직접 화면을 열어 확인한다.
4. 다음 항목을 수동으로 확인한다.
   - `배숭 언제와?` → 배송 답변 + 담당자 연결 카드
   - `환블하고 싶어요` → 환불 답변 + 담당자 연결 카드
   - `내 주뮨 보여줘` → 주문 답변
   - `결재할래` → 결제 답변
   - 상품 담기 → 장바구니 수량/총액 변화
   - 결제 진행 → 주문 정보 확인 → 데모 결제 완료 메시지
5. 변경 파일, 확인한 흐름, 아직 데모인 부분을 요약한다.

## 실제 운영 연동 시 우선순위

1. 상품/주문 API 연결
2. 서버의 결제 준비·승인 검증 API 연결
3. 배송 조회 API 연결
4. 담당자 연결(CRM, 카카오 상담, 이메일 등)
5. 대화 로그 보관 정책과 개인정보 마스킹
6. 키워드 사전과 답변을 관리자 화면에서 관리
