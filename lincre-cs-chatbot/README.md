# LINCRE Concierge

코스메틱·패션 쇼핑몰을 위한 한 화면 주문/CS/장바구니/결제 준비 챗봇 데모입니다.

## 지금 구현된 기능

- LINCRE 로고와 블루톤 별빛·말풍선 테마
- 양모 펠트 스타일의 3D 수달 상담 캐릭터
- 주문 리스트와 진행 상태 표시
- 상품을 장바구니에 담기, 수량 변경, 총액 계산
- 결제 정보 입력 화면과 결제 준비 흐름
- 배송·환불·취소·반품·교환 문의는 담당자 연결 느낌으로 응답
- `배숭`, `결재`, `환블`, `주뮨` 같은 오타도 정규화 후 인식
- 답변 문구를 여러 개 준비해 매번 똑같은 AI 답변처럼 보이지 않도록 구성
- 장바구니를 브라우저 `localStorage`에 보관

## 1. 가장 쉬운 실행 방법

1. 이 폴더를 컴퓨터에 저장합니다.
2. 폴더 안에서 터미널을 엽니다.
3. 아래 명령을 실행합니다.

```bash
python -m http.server 4173
```

4. 브라우저에서 `http://localhost:4173`을 엽니다.

Python이 없다면 VS Code의 Live Server 확장으로 `index.html`을 열어도 됩니다.

## 2. Claude Code로 수정하는 방법

터미널에서 이 폴더로 이동한 뒤 Claude Code를 실행합니다.

```bash
claude
```

그 다음 아래 문장을 그대로 붙여 넣으면 됩니다.

```text
현재 폴더의 CLAUDE.md와 README.md를 먼저 읽어줘.
이 프로젝트는 LINCRE 코스메틱·패션 주문 CS 챗봇이야.
기존 블루톤 테마, 로고, 양모 펠트 수달 캐릭터, 한 화면 주문·장바구니 흐름은 유지해줘.
새 기능을 만들기 전에 index.html / styles.css / app.js 구조를 초보자도 이해할 수 있게 설명하고,
작업 후에는 python -m http.server 4173 기준으로 동작 오류가 없는지 확인해줘.
수정이 필요하면 한 번에 하나의 기능씩 구현하고 변경한 파일과 테스트 방법을 알려줘.
```

## 3. 실제 쇼핑몰로 연결할 때

현재 결제는 데모입니다. 실제 결제를 붙일 때는 `app.js`의 `startRealPayment()`를 서버 API 호출로 바꾸고, 서버에서 PG사 결제 준비·검증을 처리해야 합니다.

- 브라우저 코드에 PG secret key를 넣지 않습니다.
- 주문 생성, 재고 차감, 결제 승인 검증은 서버에서 처리합니다.
- 배송·환불·취소·반품 연결은 상담 담당자용 API 또는 CRM/카카오 상담 채널과 연결합니다.
- 상품과 주문 데이터는 현재 샘플 배열이므로, 운영 시 쇼핑몰 DB/API로 교체합니다.

자세한 확장 순서는 `CLAUDE.md`를 참고하세요.
