# 기존 나레이션 편집

상품 URL 분석 → MP3/WAV/M4A(13–17초, 20MB 이하) 등록 → 목적 선택 → 제작.
원본 음성은 새로 합성하지 않으며 속도·내용을 변경하지 않습니다. H.264 1080×1920/30fps, AAC 192kbps로 출력합니다. 프레임 반올림으로 영상은 최대 1프레임 길어질 수 있습니다.

자동 STT는 Render 서비스 환경 변수 `OPENAI_API_KEY` 설정 시 활성화됩니다. 키는 브라우저나 저장소에 넣지 않습니다. `whisper-1`의 `verbose_json`과 단어 타임스탬프를 사용합니다. [공식 사양](https://developers.openai.com/api/docs/guides/speech-to-text).
설정 전에도 음성과 SRT 또는 JSON 타임스탬프를 함께 등록하면 외부 AI 호출 없이 제작할 수 있습니다.
JSON 예: `{"words":[{"start":0.3,"end":1.2,"word":"기존 음성 내용"}]}`. SRT의 시간은 그대로 사용하고 단어 시간을 임의 추정하지 않습니다.

상품 분석은 1시간, OCR/이미지 분석과 음성 인식은 24시간 캐시합니다. Render의 임시 파일시스템에서는 재배포 시 캐시와 업로드 파일이 사라집니다. 장기 음성 보관 서비스는 아닙니다.
나레이션은 `data/narrations/<jobId>`에 별도 저장해 렌더 완료 직후 삭제하지 않습니다. 결과 화면에서 원본 음성을 따로 내려받을 수 있습니다. 작업 종료 약 2시간 후 정리되므로 재사용할 원본은 로컬에 보관해야 합니다.

`GET /api/jobs/:id/storyboard`에 동일한 `X-Client-Id`를 전달하면 경로를 제외한 편집 계획·QA·의미 매칭 근거를 확인할 수 있습니다. 현재 의미 매칭은 OCR 키워드 기반입니다. OCR로 확인하지 못한 컷은 상품 이미지로 대체하고 경고를 반환합니다. 인물 행동을 합성하거나 확인되지 않은 성분/효과를 생성하지 않습니다. 상세페이지 사진만으로 참고 영상의 실제 촬영 장면을 복원할 수는 없습니다.

참고 분석 (2026-09-11):
- 디지털 1: 14.28초, 720×1280/30fps. 가전 전체/세부/손 사용 컷, 작은 중앙 자막, 마지막 행동 유도.
- 디지털 2: 18.16초, 720×1280/30fps. 여러 생활 공간의 사용 예, 중앙 하단 흰 자막 박스, 마지막 상품 노출.
- 건기식 1: 53.43초, 720×1280/30fps. 고민 제시 → 설명 자료 → 제품/원료 확대. 상단 짧은 자막과 강조 숫자.
- 건기식 2: 32.90초, 720×1280/30fps. 생활 고민 → 패키지/제품 확대 → 섭취 장면 → 마무리. 중앙 하단 흰 글자/검은 외곽선.

사용자의 분류를 기준으로 고정 프로필을 저장했습니다. 참고 영상 파일과 음성은 출력물에 포함하지 않습니다. 원본 영상들의 길이는 유지 대상이 아니며, 실제 등록한 나레이션 길이를 출력 기준으로 삼습니다.

검증: `node --test test/*.test.js`. 렌더 후 해상도, 코덱, 영상/음성 길이를 확인합니다. 사전 QA는 시간 연속성·자막 구간·마지막 컷·반복 소재를 검사하고 필요하면 한 번 수정합니다. 시각 의미, 실제 제품 가림 여부에 대한 완전한 자동 보증은 하지 않습니다.
